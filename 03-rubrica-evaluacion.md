## Cómo asignar los puntajes

Cada criterio tiene cinco indicadores, identificados de **a** a **e**. Se asigna un puntaje a cada indicador y se suman los cinco valores. Después se marca la casilla del nivel que contiene ese total. **Las bandas de las tablas no permiten elegir un puntaje arbitrario: el valor se obtiene de los indicadores.**

### Escala por indicador: video

| Puntaje | Descripción |
| --- | --- |
| 0 | Ausente, incorrecto o sin evidencia verificable. |
| 0,5 | Presente de forma parcial, con omisiones o errores que impiden cumplirlo completamente. |
| 1 | Correcto, completo y verificable para el alcance del tema. |

Cada criterio suma hasta **5 puntos**.

### Escala por indicador: defensa

| Puntaje | Descripción |
| --- | --- |
| 0 | No responde o mantiene una explicación fundamentalmente incorrecta. |
| 0,5 | Identifica un elemento, pero no explica su relación con el proyecto. |
| 1 | Explicación parcial, con vacíos relevantes. |
| 1,5 | Explicación esencialmente correcta, con una omisión menor. |
| 2 | Explicación correcta, justificada y autónoma. |

Cada criterio suma hasta **10 puntos**.

Todos los puntajes se asignan en **incrementos de 0,5**; no se utilizan 0,4, 0,7 u otros valores intermedios. No hay bonificaciones por avances, cantidad de commits, sofisticación audiovisual ni uso o ausencia de IA. Se evalúan los resultados, la verificación y la comprensión.

El evaluador podrá reformular una pregunta **sin proporcionar la respuesta**. Una corrección autónoma se considera en el resultado final; la ayuda sustantiva necesaria para construir la respuesta indica dominio parcial. No recordar sintaxis ni cometer un error aislado implica por sí solo puntaje cero en todo el criterio.
